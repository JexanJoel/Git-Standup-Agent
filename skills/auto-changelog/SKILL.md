# Auto Changelog

## Instructions
Generate CHANGELOG.md.

### Output Format:
Follow the **The Historian's Visual Standard (VISUAL_SPEC.md) v3.0** ONLY.

1. **Section: Release Summary**
   - Use `[BOX]Release Manifest | Version and summary here...[/BOX]`
2. **Badge: Release Type**
   - Use `[BADGE]MAJOR[/BADGE]` (or MINOR/PATCH).
3. **Verdict**
   - `─── Verdict: [Your one-line insight] ───`
